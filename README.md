# dbt + Snowflake : projet de formation

Projet issu d'une formation dbt (modélisation SQL, tests, documentation, workflow Git).
Je l'utilise comme base pour l'appliquer à des données de santé.


## Problématique
En recherche clinique, les données sont en général éparpillées sous forme de documents différents (excel,....). 
Utiliser Snowflake permet de tout réunir au même endroit et d'effectuer des calculs lourds sans faire planter son ordinateur personnel.


## Compétences pratiquées
- Transformation SQL modulaire avec dbt (staging → marts)
- Tests d'intégrité (`unique`, `not_null`)
- Entrepôt Snowflake
- Versioning GitHub (Pull Requests)

## Prochaine étape
Appliquer cette structure à un jeu de données public de cardiologie (UCI Heart Disease), puis à un premier modèle de ML.
